# Handouts LaTeX Template - TeX Live requirements
# TeX Live / tlmgr package names, one per line; comments start with #.
# Verified against the template sources and a LuaLaTeX draft compilation
# with strikeout and Citeproc support enabled, using TeX Live 2026.
# TeX Live resolves additional package and platform-specific dependencies.
# Requires LuaLaTeX and a LaTeX kernel dated 2022-06-01 or later.
# latex-bin provides the LaTeX formats; latexmk supports the README build.
#
# Includes default fonts (lm, lm-math), English/Italian language support,
# required supporting packages, and conditional strikeout/SVG support.
# Inkscape is additionally needed for SVG conversion; it is an external tool.
#
# Provider mappings for LaTeX names that differ from TeX Live package names:
#   graphicx -> graphics
#   array, longtable, tabularx, calc -> tools
#   amsthm -> amscls
#   tikz -> pgf
#   subcaption -> caption
#   centernot -> oberdiek
#   scrbase -> koma-script
